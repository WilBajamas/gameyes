# gaming_library_assessment_flutter

Flutter assessment - Gaming library with RAWG

## Getting Started

To run this, please create a `secret.env` file in the root project.
Place your api key in the file like this: "API_KEY=<your_api_key>"

After that, run `dart run build_runner build --delete-conflicting-outputs` in the terminal to generate `config_envied.g.dart`.

- Please make sure to add `secret.env` & `config_envied.g.dart` to `.gitignore`.
