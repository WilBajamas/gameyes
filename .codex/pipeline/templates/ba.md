# BA artifact templates

Read only when writing BA artifacts.

## `tech-ac.md`

```markdown
# Technical Acceptance Criteria
Source: [source]
Date: [ISO date]
BA Agent version: 1.0

## Feature summary
[concise summary]

## Technical acceptance criteria
[SOURCE-ID] CATEGORY: testable behavior.
  Failure case: prohibited or failing behavior.

## Out of scope
[items]

## Assumptions
[minor assumptions or NONE]
```

## `ambiguities.md`

```markdown
# Ambiguity Report
Source: [source]
Date: [ISO date]

## CRITICAL
[ID, ambiguity, impact, question, options] or NONE

## ASSUMPTIONS
[ID, ambiguity, chosen assumption, rationale, affected criteria] or NONE
```
